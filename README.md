# Langbot · AI 短剧作品展示页

一个暗黑电影风的 AI 短剧作品展示页，手机和电脑都能看。

## 在线预览

仓库设置里开启 GitHub Pages（Settings → Pages → Deploy from a branch → main），
就能得到一个在线链接，直接分享给别人看。

## 本地预览

把 `videos/` 文件夹里的 8 个视频放好后，直接用浏览器打开 `index.html` 即可。

## 目录结构

```
├── index.html      展示页（单文件，含样式和脚本）
├── videos/         8 个短剧视频（mp4）
└── README.md
```
